# OmniContests — Global Tech & AI Competition Radar

Live Dashboard: **[cssaritama.github.io/omnicontests](https://cssaritama.github.io/omnicontests/)**

OmniContests is an open-source, multidisciplinary competitive intelligence radar tracking over **75+ verified tech competitions, hackathons, quantitative tournaments, and security bounties** with more than **,000,000 USD** in aggregated prize pools.

### Core Disciplines Covered
- 🤖 **Autonomous SWE & Agents:** SWE-bench, Atlassian Forge, Devpost, DoraHacks
- ⚛️ **Quantum & Combinatorial Math:** Google Quantum AI, Geometric Packing
- 📈 **Quantitative Trading:** CrunchDAO, Bittensor SN6, Numerai
- 🛡️ **Web3 Security & Bug Bounties:** Sherlock, Immunefi, Cantina
- 📊 **Modern Data Systems & ML:** Kaggle, Bruin, dbt, DuckDB
